# Сравнение рекламных предложений

Один [самодостаточный бриф](../../prompts/belgrade-acquisition-brief.md) предназначен
для ChatGPT и Gemini. [Вариант ChatGPT](chatgpt-proposal.md) подготовлен отдельно.
Ответ Gemini появляется только после успешного `campaign-brief` в Actions:
артефакт `belgrade-campaign-proposal` содержит текст, исходный бриф, модель и SHA.
До успешного запуска наличие ответа Gemini не утверждается.

Workflow делает один запрос через существующий Gemini SDK, используя
`GEMINI_API_KEY` из Secrets. Модель берётся из repository variable `GEMINI_MODEL`,
по умолчанию — из действующей настройки проекта `gemini-3.8-flash`.
Наличие секрета и доступность модели проверяются фактическим запуском;
ошибка не подменяется ответом другой модели. Перезапуск повторяет API-запрос.
Вывод модели остаётся непроверенным предложением, не инструкцией для исполнения.

Автоматический запуск: изменение брифа, скрипта или workflow в main.
Повторный запуск: Actions → campaign-brief → Run workflow.
Рекламных или Telegram-клиентов в этом задании нет; публикации и изменения
рекламных бюджетов не выполняются. Запрос Gemini использует API-квоту.

Перед реальным рекламным тестом нужны аудит опубликованной ленты, проверка
возможностей кабинета и утверждение владельцем лимита расходов/убытка.
