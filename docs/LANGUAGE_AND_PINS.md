# Язык публикаций и закрепы

Заголовок и основной текст публикуются по-русски. Сербское написание допустимо
для собственных имён: улиц, площадок, организаций и названий мероприятий.
Сербские предложения из claims не переносятся в русский черновик дословно.

Обе независимые роли проверяют язык точного готового текста. Дополнительный
бесплатный `draft_language_reason` отсеивает явные непереведённые сербские
фрагменты и латинский основной текст. Это эвристика, не доказательство
безупречного перевода. Она работает даже при двух ошибочных approve/100.
Замечание попадает в обычный ограниченный цикл исправления; обе роли затем
заново проверяют исправленный текст. Проверка повторяется при импорте и
непосредственно перед доставкой. Подготовительный кэш имеет новую версию.

Для текстовых сообщений отключён автоматический предпросмотр ссылок: чужой
сербский заголовок сайта не должен визуально подменять русский пост. Подходящая
проверенная обложка может отправляться отдельным штатным медийным путём.

## Закрепы

В основном канале и связанном обсуждении закреплены только постоянные
служебные материалы. Реальные ID сохранены в `cities/belgrade/pin-policy.json`.
Новости не закрепляются. Telegram автоматически пересылает посты канала
в связанное обсуждение; серверная проверка снимает новостные закрепы,
не удаляя сообщение и не отключая комментарии.

Для этого боту нужно быть администратором обсуждения с `can_pin_messages`.
Код не добавляет бота и не расширяет права. При отсутствии доступа сохраняется
`pin_maintenance.owner_action_required`; повторной отправки новости не происходит.
Проверка не читает личные диалоги, не потребляет getUpdates и не меняет webhook.

Исключение — оплаченная и отдельно одобренная владельцем реклама с явными
`channel_message_id`, `paid=true`, `owner_approved=true`, `starts_at`, `ends_at`.
Рекламодатель, модель и сам факт заявки не могут выставлять эти разрешения.
Вне срока такой закреп снимается при проверке. Рекламных записей сейчас нет;
текущая проверка раз в три часа не является точным таймером окончания рекламы.
До продажи размещения с закрепом нужен отдельно проверенный механизм снятия
в согласованный момент; обещать рекламодателю точный срок без него нельзя.

Исправления опубликованных сообщений выполняются на месте после независимых
проверок. Старые пакеты, доказательства и sent-квитанции не переписываются:
отдельный серверный журнал corrections хранит исходный и исправленный текст.
