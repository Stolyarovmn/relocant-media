# Вечные путеводители (ОТКЛЮЧЕНО владельцем 28.10.2026)

> Владелец уточнил: канал новостной, справочные материалы не нужны, интересны только изменения. Все источники `guide_*` имеют `status: inactive` и не собираются. Механизм (сборщик, окно свежести, выбор кандидатов) оставлен для обнаружения изменений официальных страниц; включить источник можно сменой `status` на `active`.

## Исходное описание

Путеводитель — официальная страница без даты публикации (регистрация, разрешения, работа,
транспорт). Публикуется только через очередь решений владельца, со ссылкой на оригинал и
датой проверки, без ослабления проверок первоисточника.

## Как это работает

- Источник: `source_type: official_guide`, `ownership: official`, `auto_publish: false`,
  стратегия `official_guide`. Сборщик берёт видимый текст страницы (без меню и подвала) и
  связывает материал с хешем текста: изменённая страница — новый материал, а не тихая замена.
- Свежесть: `guide_freshness`. Путеводитель действует 30 дней с момента, когда этот текст был
  впервые получен с официального сайта (`ingested_at`). Затем материал истекает, и страницу
  нужно проверить заново. Новости по-прежнему подчиняются своему правилу (`freshness_decision`);
  выбор между правилами делает одна функция `evidence_freshness`.
- Очередь: причина `source_auto_publish_disabled`, затем две независимые проверки по живому
  источнику, затем кнопки «В редакцию» и «Отклонить». Категория может быть любой, в том числе
  высокорисковой (иммиграция): официальный первоисточник обязателен всегда.
- В тексте для владельца и в публикации стоит строка «Проверено по официальному источнику:
  ДД.ММ.ГГГГ». Дата берётся из времени живой проверки источника независимыми ревью.
- Перед публикацией выполняются прежние проверки: живая сверка страницы, свежесть, дедупликация,
  политика аудитории, фиксированный канал.
