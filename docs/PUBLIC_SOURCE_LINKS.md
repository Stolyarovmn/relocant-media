# Короткая публичная ссылка на первоисточник

Публичный Telegram-пост не должен показывать длинный сырой URL первоисточника.
Редакционный пакет и evidence по-прежнему сохраняют полный точный URL для аудита,
повторной сверки и source-revision контроля.

Перед отправкой транспорт детерминированно преобразует строку вида:

```text
Источник: https://official.example/very/long/path?query=value
```

в видимую строку:

```text
Источник
```

и передаёт исходный URL отдельно как Telegram `text_link` entity. Поэтому ссылка
остаётся кликабельной, но URL не занимает место в тексте. Преобразование применяется
одинаково к обычным сообщениям и caption фото/альбомов. Link preview остаётся выключен.

Offset и length entity считаются в UTF-16 code units, как требует Bot API; это
покрыто тестом с кириллицей и emoji. При неоднозначных двух строках `Источник: URL`
или URL с credentials транспорт прекращает отправку вместо выбора ссылки наугад.

Writer не должен вставлять raw source URL в заголовок или основной текст. Полный
URL остаётся частью evidence/review package; транспорт добавляет компактное публичное
представление только на границе Telegram. Это не меняет фактчек, источник доказательства,
редакционный пакет или правила повторной проверки.
