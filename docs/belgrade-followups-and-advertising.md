# Правила для напоминаний, изменений и рекламы

- Подтверждённое плановое отключение: публикуем заранее после обычной проверки.
  Накануне в 20:30 по Белграду перепроверяем время и зону по первоисточнику.
  Вода, свет, дороги и афиша берутся из проверяемых адаптеров. В выпуск помещается
  до четырёх пунктов; отдельный приоритетный URL закрепляется в digests.yaml.
  Если расписание или зона поменялись, старую карточку в напоминание не ставим.
  Если новость в сводке, даём ссылку на отдельную публикацию, когда она есть.
  Отдельное напоминание по одному отключению отправляем ответом на этот пост.
  Сводку не используем как исходный пост.
- Перенос, отмена, изменение списка адресов или границ: перепроверяем по
  официальному источнику. В заголовке называем изменение, в тексте сначала даём
  актуальные условия, затем при необходимости «было → стало». После проверки
  обновление той же публикации выпускаем ответом на исходный отдельный пост.
  Значимые изменения опубликованного материала по тому же официальному URL
  автоматически ставятся на полное повторное ревью. Связь с исходным постом
  сохраняется. Новый URL без подтверждённой связи требует редакционной проверки.
- На карте плановые работы помечаем будильником. Отработанные работы доступны
  по старой ссылке из поста и исчезают из обычного списка. Точки поселений без
  точных данных — ориентиры, границы домов или всей общины не рисуем.
- В календарь передаём только подтверждённое расписание. При импорте файла
  указываем напоминание за сутки. Это разовое добавление: если время изменится,
  читателю нужно обновить свою запись самостоятельно.
- Рекламный пост: первая видимая строка **Реклама**, дальше название или имя
  рекламодателя, предложение, условия, действие. В редакторе допустим Markdown;
  при публикации применяем поддерживаемое Telegram форматирование. В обычные
  новости, органические рекомендации и редакционные сводки рекламу не включаем.
- Рекламное событие на карте получает звезду и подпись «Реклама» при подтверждённой
  оплате, согласовании владельцем и отдельной покупке показа на карте
  (map_featured), только в пределах срока размещения. Органическая карточка
  без звезды может остаться до окончания события. Отдельное заведение задаётся
  в записи кампании ключом place: title, source_url и venue с name, address,
  latitude и longitude. Указываются опубликованный channel_message_id,
  starts_at, ends_at и три подтверждения: paid, owner_approved, map_featured.
  Карточка кафе исчезает по завершении кампании и не попадает в календарь.
  Без оплаченных кампаний раздел остаётся обычной афишей. Черновик с обязательной
  первой строкой «Реклама» готовится командой python -m
  relocant_media.ops.ad_post_preview; команда ничего не отправляет и не списывает.
- Обложки сводок берём из двух пулов фотографий Белграда. Индекс меняется по
  местной дате; автор, лицензия и кадрирование указаны в подписи. При отсутствии
  пригодного изображения или слишком длинном тексте сводка выходит без него.
  Режим digest-preview в Editorial Actions собирает утренний выпуск на выбранную
  дату из проверенной копии базы, показывает фото, источники и ссылку карты в логе.
  Он не пишет в очередь, не отправляет сообщения и не выкладывает GitHub Pages.
