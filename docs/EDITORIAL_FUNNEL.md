# Проверки помогают выпуску

Лимит основного цикла — пять рассмотренных кандидатов, а не пять опубликованных
постов. Если слоты занимают общеполитические и зарубежные новости, корректный отказ
по каждой из них может оставить весь выпуск без полезного местного материала.
Поэтому исправление очереди начинается с выбора кандидатов, а не отмены фактчека.

Порядок меняется до моделей. СМИ с подтверждённой связью с городом и практическим
поводом (погода, затопления, аэропорт, задержки, городской транспорт, отключения,
афиша) не остаются ниже любой общей официальной заметки. Связь проверяется в
заголовке и начале текста по псевдонимам города. Важные официальные транспортные
предупреждения, приоритетная предложка и действующие полосы внимания сохраняются.
Иностранная тема не получает транспортный приоритет по одному слову «перекрытие».

Это только сортировка: остальные кандидаты сохраняются, количество доступных
кандидатов не уменьшается, решения и квитанции при выборе не записываются.
Фактчек, перевод, подтверждённая география, источники, независимые ревью и запрет
повторной отправки сохраняются. Лимиты модельных обращений, расписания и бюджет
этим изменением не увеличиваются.

Результат следует проверять по новым завершённым циклам: какие темы заняли слоты,
какие причины отказа сохранились и сколько полезных материалов дошло до канала.
Сам рост количества загруженных документов не доказывает рост количества новостей.
Исторические пропуски, истёкшие события и технические ожидания следует считать
раздельно, а не выдавать за одну «очередь готовых новостей».

Неполная карта — техническое ожидание, не отрицательная оценка темы. После появления
проверенного адаптера/реестра неизданный пакет должен повторно пройти обычную
редакционную обработку; этот путь описан в EVENT_MAP_COMPLETENESS.md.
