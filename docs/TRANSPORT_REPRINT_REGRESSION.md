# Регрессия реального транспортного повтора

При повторе исходных статей raw356 и raw352 исправление PR117 продолжало возвращать
`same_event=false`. Прежний тест содержал сокращённый искусственный текст вместо
двух точных сохранённых документов.

Причины:
- `SequenceMatcher` по умолчанию игнорировал часто встречающиеся буквы в длинных
  строках: сходство0.577 вместо0.863.
- Эквивалентные сербские формы `udvosmerena` и `dvosmerna` давали разные признаки
  двустороннего движения.

Теперь сравнение сохраняет буквы, эти две формы дают один признак; однонаправленное
движение остаётся отдельным. Пороги0.85/0.80, совпадение маршрутов, остановок,
действий, издателя и временного окна сохранены. Изменение отрицания отклоняет
объединение. Явный год события учитывается; пропущенный год берётся из даты
публикации, без обращения к текущим часам. Изменённые дата/год, маршруты, остановки
и условия проверяются отрицательными примерами.

Сравнение строк без эвристики популярности ограничено8000символами каждого
нормализованного тела. Более длинный текст не объединяется этим правилом, чтобы
исключить неограниченную квадратичную работу. Точный URL/хеш и межисточниковая
логика остаются прежними. Предложка и отложенная смысловая группировка обращений
не затрагиваются.

Фикстура `beograd_transport_reprint_20261023.json` содержит точные публичные
evidence двух официальных сообщений, с URL и исходной датой публикации.
Исходные редакционные пакеты, квитанции и история удаления повтора не изменяются.
