# Пилот сводок «Еду в Белград»

С 13 по 27 ноября 2026 года открыто 28 слотов в часовом поясе `Europe/Belgrade`.
Первый слот — 13 ноября в 20:30, последний — 27 ноября в 07:30. После него выпуск
заканчивается автоматически. При задержке Actions выпуск может выйти в пределах 45 минут
от слота. Штатные редакционные запуски подхватывают пропущенный слот в том же окне.

- **Белград сегодня, 07:30.** От двух до четырёх пунктов. Предупреждение РХМЗ для Белграда
  ставится первым. Далее идут перекрытия, изменения маршрутов, прогноз и отключения,
  действующие в этот день. У каждого пункта есть ссылка. Если доступны подтверждённые
  участки, кнопка «Посмотреть на карте» открывает именно их.
- **Главное за день, 20:30.** Два–четыре пункта из уже выпущенных сегодня постов с
  короткой выдержкой, когда она добавляет детали. Если к утру действует подтверждённое
  объявление, оно может стать последним пунктом. Приоритет у транспорта, коммунальных
  изменений и других новостей с практическими последствиями.

Формат рассчитан на минуту чтения. Сводка выходит с `#Сводка` и без звукового уведомления.
При наличии менее двух полезных пунктов выпуск пропускается. Утренний прогноз берётся из
[таблицы РХМЗ](https://www.hidmet.gov.rs/ciril/prognoza/index.php), предупреждения — из
[официальной ленты РХМЗ в MeteoAlarm](https://feeds.meteoalarm.org/feeds/meteoalarm-legacy-atom-serbia).
При недоступности прогноза или несовпадении даты погодный пункт опускается. Срочные новости
выходят через штатную редакцию по мере готовности.

В обычной новости допускается один тематический эмодзи рядом с подписью. Для происшествий
с пострадавшими и обвинений достаточно текста. В сводке эмодзи используются перед подписью
темы, максимум три на выпуск. Смысл подписи полностью передаётся словами.

Каждый выпуск имеет ключ города, местной даты и времени. Каноническое хранилище сохраняет
намерение отправить сообщение до вызова Telegram и квитанцию после него. Если Telegram
не подтвердил результат, тот же выпуск автоматически не повторяется.

По окончании пилота сравнить для каждого формата выходы, просмотры и пересылки через
24 часа. Времена 07:30 и 20:30 — условия пилота. Их пригодность оценивается по данным канала.
