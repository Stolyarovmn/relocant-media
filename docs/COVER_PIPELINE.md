# Выбор обложки как часть редакционного цикла

Короткая новость получает максимум одну подходящую обложку по умолчанию.
Текстовый альбом, пересказывающий подпись, не является стандартом. При отсутствии
подходящего изображения можно публиковать текст; собственная карточка создаётся
только когда она действительно помогает, а не как обязательная замена любой фотографии.

Последовательность: источник → обнаружение основных изображений → визуальная
классификация и совпадение события/года → оценка основания использования → выбор
формата → скачивание снимка с SHA256 → два независимых медиа-ревью → MediaRelease
с атрибуцией → fake-проверка. Реальная отправка требует отдельного разрешения.

## Реализованный адаптер

Чукарица: извлекается только Featured Image основной статьи, без footer, логотипов,
связанных новостей и произвольного og:image. HTTPS, домен и путь загрузок проверяются
перед каждым переходом; размер ограничен10МБ, формат определяется по байтам.
Новый каталог и имя по SHA256 сохраняют историю. Другие источники пока требуют
отдельных проверенных адаптеров или явного ручного подбора, а не угадывания URL.

```sh
APP_ENV=staging python -m relocant_media.ops.cover_cli \
  --article-url https://www.cukarica.rs/vest/655-poziv-za-izlagace-na-cukarickom-festivalu-zimnice/ \
  --output /new/run/discovery
```

На Windows задайте переменную окружения отдельно. Команда не использует БД,
Telegram, AI API, токены или .env. Первый manifest содержит кандидатов, но не
автоматическое заключение об их типе или правах. Исходная HTML-страница сохранена.

Редакционный агент просматривает изображение, сверяет его с событием и заполняет
массив CoverAssessment в отдельном JSON. Поля описаны в services/cover_selection.py.
Для основания использования сохраняются метод, URL доказательства, объяснение,
статус оценки и роль оценившего. «Официальный сайт» — происхождение, не лицензия.
`current_event_reporting` означает оценённое основание информационного использования,
а не полученное согласие правообладателя; применять его ко всем картинкам нельзя.

```sh
python -m relocant_media.ops.cover_cli --article-url <тот же URL> \
  --assessments /run/assessments.json --event-year 2026 --output /new/run/selected
```

Оценки связываются с обнаруженными URL и конкретной статьёй. Скачиваются только
выбранные материалы. `publication_permitted=false` остаётся в manifest: выбор
обложки не заменяет проверку готового текста и самих байтов двумя рецензентами.

## Правила выбора

- Афиша текущего события с подтверждённым соответствием — первый кандидат.
- Затем подходящее фото текущего события; архив требует известного года и подписи.
- Неизвестный тип, несовпадение события/года, логотип или незавершённая оценка прав
  не дают обложку. Решение без картинки не блокирует редакционный текст.
- Альбом возможен только с `--allow-album`, минимум двумя снимками с отдельной
  визуальной пользой; максимум пять. Само количество доступных картинок не аргумент.
- Афиша сохраняется целиком. Не удаляйте логотипы, автора и существенные условия.
  «Позив за излагаче» обозначает приглашение продавцов; телефон регистрации нельзя
  представить справочным для посетителей без подтверждения.

Для MediaAsset добавлен origin=official_poster. Он требует атрибуции в caption.
Штатный сервис принимает исходный проверенный текст плюс отдельный блок точных
атрибуций/архивных подписей из assets; произвольный новый текст этим путём не проходит.
Вся подпись и метаданные по-прежнему связаны с двумя медиа-ревью.
См. [EDITORIAL_MEDIA.md](EDITORIAL_MEDIA.md) для пакета и доставки.
