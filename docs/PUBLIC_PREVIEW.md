# Публичные наблюдения Telegram без MTProto

Команда получает только общедоступную HTML-страницу `https://t.me/s/{channel}`.
Авторизация, подписки, отправка сообщений и доступ к закрытым каналам отсутствуют.

```sh
relocant-public-preview city_news --output snapshot.json
```

Без `--output` снимок JSON выводится в стандартный вывод. Имя канала передаётся
без `@` и URL: от 5 до 32 ASCII-символов, первая — буква, далее буквы, цифры и `_`.
Редиректы не выполняются. Ссылки и инструкции из текста постов не исполняются.
Сборщик не использует хранилище метрик, Telegram-токены или MTProto-настройки.

Снимок содержит время получения `fetched_at` и время публикации `published_at`
в UTC с часовым поясом. `views` содержит `value`, исходную строку `raw` и
`approximate`: значения с K/M приблизительные, их нельзя считать точными.
Отсутствующий или неподдерживаемый счётчик — `null`, а видимый ноль — `0`.
Реакции, комментарии и пересылки пока всегда `null`: достоверного универсального
извлечения этих показателей из публичного превью нет.

Превью показывает ограниченное окно постов и может быть недоступно. Отсутствие
поддерживаемых постов считается ошибкой, а не пустой успешной статистикой.
Снимки не дают статистику подписчиков, кликов, удержания или точного охвата.
Для сравнения сохраняйте повторные снимки одного поста в сопоставимом возрасте;
не выводите причинность и не меняйте редакционные веса по единичному наблюдению.

JSON — данные из недоверенного источника. При дальнейшем показе в HTML или
таблицах применяйте экранирование, а при импорте в Sheets используйте режим RAW,
чтобы текст не интерпретировался как формула. Ошибки CLI не содержат HTTP-ответы
или содержимое секретов.
