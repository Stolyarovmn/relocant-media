Как работает редакция

Схема возможностей кода. Фактические запуски и включение отправок проверяйте ниже по наблюдениям.

1. Поиск · сборщики и ChatGPT

Код читает официальные сайты и афиши. Telegram и новостные ленты дают темы для поиска первоисточника. Облачный поиск ChatGPT передаёт ссылки через отдельный вход discovery, если он подключён; ответ чата сам по себе не попадает в очередь.

2. Допуск · правила кода

Проверяются источник, дата публикации, свежесть, дубли и связь материалов одного события. Частный текст предложки не становится доказательством.

3. Подготовка · Gemini

Отбор → утверждения с цитатами → проверка по evidence → русский черновик. Перевод встроен в подготовку. Дополнять материал можно только подтверждёнными фактами; имя модели определяется настройкой и журналом запуска.

4. Ревью · факты и польза

Два отдельных вызова проверяют точный черновик. Это две роли, а не обязательно разные модели. После исправления обе проверки выполняются заново. Рискованные категории требуют отдельного review владельца. Jev — наблюдатель, без права одобрять выпуск.

5. Медиа · отдельный допуск

Изображения требуют подтверждённых происхождения и прав, точных файлов и двух медиа-ревью. Без подготовленного безопасного пакета предусмотрен текстовый пост.

6. Доставка · Telegram Bot API

Перед отправкой первоисточник читается заново. Попытка фиксируется до запроса. Только sent с message ID подтверждает доставку; sending и uncertain запрещают слепой повтор.

Предложка · приоритетная очередь

Входящие сохраняются пачкой; разрешённые ссылки независимо загружаются. Подтверждённый новый повод проходит ту же редакцию. Без первоисточника — ожидание и запрос уточнений. Реклама и исправления имеют отдельные процедуры; обратная связь включается отдельно.

Другие процессы

Мониторинг изменений опубликованных источников, owner review, модерация обсуждений, рекламные обращения и аналитика без расходов, резервирование Drive, проверка источников, campaign brief, Jev smoke, ежедневный отчёт и CI. Наличие кода не подтверждает включение процесса.
